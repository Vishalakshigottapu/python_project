A list [] stores several records. A dictionary {} stores named fields.

for visits each item; while repeats until break stops it.
if/elif/else selects the block matching a condition.
Indentation shows which statements belong to each block.
def defines a function; return sends its answer back to the caller.
class groups operations; self refers to the current ExaminationSystem object.
__init__ runs when an ExaminationSystem object is created.
None means that no value has been found or supplied.

'r' is the default reading mode; 'w' creates a file; 'a' appends records.
encoding='utf-8' supports text characters; newline='' lets csv handle line ends.
raise reports an error; try/except catches an error and displays a message.
f'...' inserts values written inside braces into a message.

+= 1 increases a counter by one. len(...) counts items.
int converts text to a whole number; float converts it to a decimal number.

PROGRAM FLOW
1. Create the system object; create missing student/results files.
2. Show the menu repeatedly until the user chooses Exit.
3. Run the chosen method, catching file and value errors.
4. During an exam, validate the student, category and question count.
5. Randomly sample that category's questions; validate each answer.
6. Count correct, wrong and skipped answers; calculate and save the result.
7. Read saved attempts to produce the result summary.

FEATURES AND THE METHODS TO STUDY
Registration: register - checks the ID and saves a student dictionary.
Question bank: questions and add_question - validate/load/save questions.
Categories: take_exam - collects unique categories and sorts their names.
Random selection: take_exam - random.sample(pool, count).
Exam attempt: take_exam - loops through selected questions and their options.
Answer validation: ask - accepts exactly one allowed answer/menu character.
Negative marking: take_exam - score = correct * 4 - wrong.
Scoring: take_exam - maximum is count * 4; percentage is score/maximum*100.
Result generation: take_exam - displays totals and saves a result dictionary.
Result summary: summary - filters attempts by ID and averages percentages.

HELPER FUNCTIONS
read_records checks the header and each record before returning a list of
dictionaries. append_record checks the existing file then writes one record.
ask repeats the prompt until the input is valid.

014: def read_records(filename, fields):
015:     """Read a CSV-formatted TXT file and check its structure."""
016:     with (BASE / filename).open(encoding='utf-8', newline='') as file:
017:         reader = csv.DictReader(file)
018:         if reader.fieldnames != fields:
019:             raise ValueError(f'{filename}: incorrect column headings.')
020:         rows = list(reader)
021:     for row in rows:  # Check each saved record separately.
022:         if set(row) != set(fields):
023:             raise ValueError(f'{filename}: extra or missing columns.')
024:         for value in row.values():
025:             if value is None:
026:                 raise ValueError(f'{filename}: incomplete record.')
027:     return rows

030: def append_record(filename, fields, row):
031:     """Append one record; validate the existing file before changing it."""
032:     read_records(filename, fields)

034:         csv.DictWriter(file, fieldnames=fields).writerow(row)

042:             continue

044:             return value
